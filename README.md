#  SkillBridge AI

**SkillBridge AI** is an AI-powered career roadmap generator that helps students, fresh graduates, and aspiring software professionals identify the skills they need for their desired tech career. Based on a user's current knowledge, experience, and career goal, the application generates a personalised learning roadmap, highlights skill gaps, recommends projects, and suggests learning resources.



##  Problem Statement

Many students know the career they want—such as AI Engineer, Backend Developer, Data Analyst, or Cybersecurity Specialist—but struggle to answer important questions like:

* What should I learn first?
* Which skills am I missing?
* What projects should I build?
* How long will it take to become job-ready?
* Which technologies are most important?

SkillBridge AI solves this problem by acting as an AI-powered career coach that creates a structured, personalised learning plan for every user.

# 🤖 AI Feature

## AI Career Roadmap Generator

The core AI feature analyses the user's profile and generates a customised roadmap for achieving their target career.

### User Input

* Current education
* Existing skills
* Experience level
* Target career
* Weekly study hours
* Preferred learning style

### AI Output

The AI generates:

* Personalised learning roadmap
* Skill gap analysis
* Missing technologies
* Recommended projects
* Estimated completion timeline
* Career guidance

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/minahil7265/skillbridge-ai-.git
```

Move into the project:

```bash
cd skillbridge-ai-
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:5173
```
