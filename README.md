# SkillBridge AI

AI-powered career roadmap generator. Tell it where you are and where you want to go, and SkillBridge AI builds a personalized learning plan with skill-gap analysis, project recommendations, curated resources, and interview prep.

## How it works

```
User Input (profile form)
    ↓
Frontend (app/analyzing/page.tsx)
    ↓
POST /api/roadmap
    ↓
Server-side LLM call (Groq API — llama-3.3-70b-versatile)
    ↓
Structured JSON response
    ↓
Zod schema validation
    ↓
Personalized Career Roadmap
    ↓
Frontend display + optional Supabase storage + PDF export
```

The roadmap is generated by a real LLM (Groq's `llama-3.3-70b-versatile` model). The user's profile — current skills, experience level, career goal, weekly hours, learning style — is sent to the server-side API route, which builds a structured prompt, calls the LLM, validates the JSON response with Zod, and returns a personalized roadmap.

Different inputs produce different roadmaps. The AI personalizes:

- Skill-gap analysis (existing vs. missing vs. priority skills)
- Learning phases with specific skills and tasks per month
- Project recommendations across difficulty levels
- Curated resources with real URLs
- Resume tips and interview questions tailored to the target role

## Tech stack

- **Next.js 13** (App Router)
- **Groq SDK** (`groq-sdk`) — server-side LLM calls
- **Supabase** — authentication and roadmap storage
- **Zod** — input and output validation
- **Tailwind CSS + shadcn/ui** — UI
- **jsPDF** — PDF export
- **Framer Motion** — animations

## Environment variables

Copy `.env.example` to `.env` and fill in:

```env
# Supabase (client-side)
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=

# Groq API key (server-side only)
# Get yours at https://console.groq.com/keys
GROQ_API_KEY=
```

The `GROQ_API_KEY` is only used in the server-side API route (`app/api/roadmap/route.ts`). It is never exposed to the browser.

## Running locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`, fill in the profile form, and generate a roadmap.

## API reference

### `POST /api/roadmap`

**Request body** (JSON):

```json
{
  "name": "Alex Johnson",
  "education": "Bootcamp Graduate",
  "currentSkills": ["HTML", "CSS", "JavaScript"],
  "experienceLevel": "beginner",
  "careerGoal": "Frontend Engineer",
  "weeklyHours": 10,
  "learningStyle": "visual",
  "language": "English"
}
```

**Response** (JSON):

```json
{
  "roadmap": {
    "id": "roadmap_1234567890_abc123",
    "createdAt": 1234567890,
    "profile": { ... },
    "currentLevel": "Complete Beginner",
    "targetLevel": "Mid-Level Frontend Engineer",
    "estimatedWeeks": 16,
    "phases": [ ... ],
    "skillGaps": [ ... ],
    "projects": [ ... ],
    "resources": [ ... ],
    "resumeTips": [ ... ],
    "interviewQuestions": [ ... ],
    "demandScore": 88
  }
}
```

If `GROQ_API_KEY` is not configured, the API returns a 503 error — the app requires a valid Groq API key to generate roadmaps.

```
  ai/career-coach.ts       # Groq LLM integration + Zod validation

  pdf-generator.ts         # PDF export
  careers.ts               # Career track metadata (landing page UI only)

```
